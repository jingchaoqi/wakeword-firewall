# 唤醒词防火墙

> 你在电脑上看视频，视频里的人说了一句「小爱同学」——桌上的手机亮了。

这是一个 Chrome 扩展。它在唤醒词播出来**之前**把那一小段声音静音掉，
让视频没法唤醒你身边的手机和音箱。

所有识别都在你自己的电脑上完成，**不上传任何音频，也不发送任何网络请求**。

## 安装

本扩展尚未上架应用商店，需要手动安装。整个过程大约两分钟，不需要任何技术基础。

**支持的浏览器**：Chrome、Edge，以及其他基于 Chromium 的浏览器
（Brave、Vivaldi、Opera、360 极速浏览器等），版本需在 94 以上，建议使用最新版。
Windows、macOS、Linux 均可。

> Safari 和 Firefox 使用不同的扩展体系，暂不支持。
> 手机浏览器不支持扩展，因此本扩展只能在电脑上使用。

### 第 1 步 · 下载

打开 [**Releases 页面**](https://github.com/jingchaoqi/wakeword-firewall/releases)，
在最新版本下方的 **Assets** 里，下载 `wakeword-firewall-x.y.z.zip`
（`x.y.z` 是版本号，例如 `0.1.0`）。

文件约 15 MB，其中大部分是本地语音识别模型。

### 第 2 步 · 解压

把压缩包解压到一个**你不会误删的位置**，例如「文档」文件夹。

> **重要：解压后的文件夹不能删除，也不要再移动。**
> 浏览器每次启动都会从这个位置读取扩展，文件夹没了扩展就失效了。
> 不要留在「下载」文件夹里，那里容易被顺手清理掉。

解压后你会得到一个文件夹，里面能看到 `manifest.json`、`src`、`vendor` 等文件。
**记住这个文件夹的位置**，下一步要用。

> 如果解压后打开只看到一个同名的文件夹、里面才是这些文件，
> 那就以**里层**那个文件夹为准。

### 第 3 步 · 装进浏览器

<details open>
<summary><b>Chrome / Brave / Vivaldi / 360 极速等</b></summary>

1. 在地址栏输入 `chrome://extensions` 并回车
2. 打开**右上角**的「开发者模式」开关
3. 左上角会出现三个按钮，点击「**加载已解压的扩展程序**」
4. 选择第 2 步解压出来的文件夹，点「选择」

</details>

<details>
<summary><b>Microsoft Edge</b></summary>

1. 在地址栏输入 `edge://extensions` 并回车
   （也可以点地址栏右侧的扩展图标，再选「管理扩展」）
2. 打开页面上的「**开发人员模式**」开关
3. 点击「**加载解压缩的扩展**」按钮
4. 选择第 2 步解压出来的文件夹，点「选择文件夹」

> Edge 的开关和按钮位置与 Chrome 略有不同，名称也是「开发人员模式」
> 而非「开发者模式」，在页面上找一下即可。

</details>

安装成功后，扩展列表里会出现「唤醒词防火墙」，并且**自动打开一个引导页**。

### 第 4 步 · 把图标固定到工具栏

浏览器默认会把新装的扩展折叠进地址栏右侧的**拼图图标**里。
本扩展的全部功能都在它的图标上，建议固定出来：

1. 点击地址栏右侧的拼图图标
2. 找到「唤醒词防火墙」，点击它右边的**图钉**图标

Edge 的操作相同，图钉图标在扩展名称右侧。

### 第 5 步 · 自检

在自动打开的引导页上，点「**运行自检**」。
它会在本地跑一遍完整的识别流程，确认扩展工作正常。不使用麦克风，也不联网。

看到「检测引擎工作正常」就可以开始用了——打开任意视频网页即自动生效。

### 遇到问题？

**找不到「开发者模式」开关**
确认地址栏输入的是 `chrome://extensions` 或 `edge://extensions`，
而不是在应用商店页面。开关在 Chrome 的右上角、Edge 的左侧栏底部。

**点了「加载已解压的扩展程序」后提示「清单文件缺失或不可读取」**
选错文件夹了。要选的是**直接包含 `manifest.json` 的那一层**，
而不是它的上一级。

**浏览器每次启动都提示「请停用开发者模式扩展程序」**
这是 Chrome 对手动安装扩展的固定提醒，点「取消」即可，不影响使用。
上架应用商店后就不会再有这个提示。

**扩展列表里显示了，但视频网页上没反应**
装好后需要**刷新已经打开的视频网页**——扩展要在网页加载时就开始工作。

### 备选：自己构建

如果 Releases 页面暂时没有可下载的版本，或者你想从源码构建，
需要 `git`、`cmake`、`python3` 和能运行 emscripten 的环境，
构建过程约占用 3 GB 磁盘空间。

```bash
git clone https://github.com/jingchaoqi/wakeword-firewall.git
cd wakeword-firewall
./extension/tools/build-all.sh
```

这条命令会自动完成全部步骤：编译识别引擎、下载模型、打包。
**首次运行需要 20 到 40 分钟**，之后再运行会跳过已完成的部分。

完成后按上面第 3 步操作，选择仓库里的 `extension` 文件夹即可。

> 为什么必须自己编译：语音识别引擎 sherpa-onnx 的官方发布中，
> 没有提供关键词检测功能的浏览器版本，只能自行构建。
> 详细说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 开始使用

安装完成后，**打开任意视频网页即可自动生效**，无需任何操作。

### 工具栏图标在说什么

浏览器右上角的扩展图标会实时反映当前网页的状态：

| 图标显示 | 含义 |
|---|---|
| **数字** | 当前网页已经屏蔽了几次唤醒词 |
| **`!`** | 当前网页无法拦截，原因见下方[哪些情况挡不住](#哪些情况挡不住) |
| **`3!`** | 已屏蔽 3 次，但这个网页还有一部分内容无法拦截 |
| 空白 | 当前网页还没有检测到需要处理的音频 |

数字按网页单独计算，切换网页会自动归零。
把鼠标停在图标上，会显示一句更具体的说明。

**扩展不会悄无声息地失效。** 只要当前网页无法拦截，图标角上一定会出现 `!`，
这与任何设置开关都无关。

### 设置面板

点击工具栏图标打开设置面板。

**顶部是屏蔽统计**，分「本页屏蔽统计」和「历史屏蔽统计」两栏，按唤醒词分别列出次数。
想知道哪个词最常被视频念到，看历史那一栏。
如果当前网页有无法拦截的内容，上方会有一条橙色说明解释原因。

**下面可以调整五项设置：**

| 设置 | 说明 |
|---|---|
| **启用防护** | 总开关。切换后需要刷新网页才会生效，面板里会提示 |
| **静音时长** | 唤醒词之后再多静音多久，默认 0.3 秒。详见下方说明 |
| **提示开关** | 两个：拦截时是否弹出悬浮提示、当前页不支持时是否弹出提示 |
| **外观** | 三档配色与强调色，详见下方说明 |
| **唤醒词表** | 增删屏蔽词，见[管理屏蔽词](#管理屏蔽词) |

**关于静音时长。** 视频里的唤醒词后面往往紧跟着一句指令，比如「小爱同学，打开卧室灯」。
只静音唤醒词本身，你的设备不会被唤醒，但那句指令仍会播出去——如果被**别的**设备听到，
仍有可能被执行。

| 时长 | 效果 |
|---|---|
| 小于 0.6 秒 | 只静音唤醒词本身 |
| 1 至 3 秒 | 可以挡掉「打开卧室灯」这类短指令 |
| 更长 | 几乎能挡住所有指令，代价是每次多静音一段正常内容 |

面板里的滑块下方会随着你的调整实时显示对应说明。

**关于外观。** 提供三档配色，滑杆切换，默认为「月白」：

| 名称 | 风格 |
|---|---|
| **月白** | 米白，偏暖（默认） |
| **烟霭** | 浅灰，偏冷 |
| **玄墨** | 深灰 |

强调色可以自选任意颜色。每一档的文字颜色都已配好，
即使你选了与背景过于接近的强调色，扩展也会自动调整到能看清为止。
悬浮提示和设置面板共用同一套外观，修改后立即生效，无需刷新。旁边有「恢复默认」。

## 管理屏蔽词

扩展默认已经内置了常见的唤醒词：小爱同学、小度小度、天猫精灵、你好小娜、
小艺小艺、小布小布，以及几个容易被误听成唤醒词的近音变体。

### 添加

打开设置面板，在「唤醒词表」上方的输入框里**直接输入中文**，按回车或点「添加」。

扩展会显示转换结果供你核对，然后点「**保存词表**」，
再**刷新视频网页**，新词就生效了。

转换全程在本地完成，不联网。

### 删除

词表框就是普通文本，**删掉对应的那一行，点「保存词表」，刷新网页**即可。

想恢复成出厂词表，把框里内容**全部清空**再保存。

### 可以添加哪些词

**几乎所有汉语词汇都可以**，包括繁体字，共覆盖 20840 个汉字。
词表长度也不受限制——实测词表有 1 条和有 1001 条，识别速度没有差别。

但有四点需要留意：

**一、多音字可能取错读音。** 扩展按单字查读音，不做词语层面的判断，
所以「重庆」会被当成 zhòng qìng、「银行」会被当成 yín xíng。
读音错了不会报错，只是这个词永远匹配不上。

添加后转换结果就显示在你眼前，觉得读音不对可以直接在词表框里修改那一行，
格式是「声母 空格 带声调的韵母」。

**二、只支持普通话。** `Hey Siri`、`OK Google`、`Alexa` 这类外语唤醒词无法添加，
方言和外来音同理。

**三、添加的是一个确切读音，不是「这个词」。** 添加了「小爱同学」，
视频里念成「小菜同学」「小坏同学」是拦不住的。
如果你的设备容易被这些变体唤醒，把变体也添加进词表即可。

**四、两个字的词误报风险较高。** 音节越少越容易被正常说话内容碰上，
四个字的词最稳妥。

> 每行末尾还可以追加 `:数字` 提高触发概率、`#数字` 提高触发门槛，
> 用来单独调整某个词的灵敏度。默认值分别是 2.0 和 0.25。

## 隐私与权限

**这个扩展不会把任何东西发到网上。** 识别模型和引擎都打包在扩展内部，
音频从头到尾没有离开你的电脑。

安装时浏览器会列出一串权限，逐条说明如下：

| 权限 | 用途 |
|---|---|
| 读取和更改所有网站上的数据 | 唤醒词可能出现在任何视频网站，无法预先列出白名单 |
| 存储 / 无限存储 | 保存你的词表、设置和统计数据 |
| 标签页 | 设置面板需要知道当前是哪个网页，才能显示对应的统计 |
| 离屏文档 | 识别过程在一个独立的后台文档中运行 |

**没有**申请网络请求拦截、Cookie、浏览历史、标签页录制等权限。

## 哪些情况挡不住

以下情况受技术条件限制，无法拦截：

| 情况 | 原因 |
|---|---|
| **有版权保护的内容**（Netflix 等） | 音频经过加密，浏览器扩展拿不到原始声音 |
| **杜比音轨** | Chrome 不自带这种音频格式的解码器 |
| **网络通话**（视频会议等） | 实时通话没有缓冲，来不及提前识别 |
| **浏览器以外的一切** | 本地播放器、微信视频、系统提示音、别人手机外放 |
| **手机上看视频** | 移动端浏览器基本不支持扩展 |

以上五种情况，工具栏图标角上**一定会出现 `!`**，不会让你误以为还在保护。

还有两种情况是**没有提示的**：唤醒词的近音变体（如「小菜同学」），
以及非普通话的唤醒词。此时防护本身正常工作，只是这个读音不在它认识的范围内。
详见上方[可以添加哪些词](#可以添加哪些词)。

## 常见问题

**图标角上一直显示 `!`**
把鼠标停在图标上，或点开设置面板，顶部会说明具体原因。
多数情况属于上一节列出的技术限制。

**视频里明明说了唤醒词，却没有被静音**
先确认设置面板里的「启用防护」是打开的。
另外，扩展需要提前读取尚未播放的音频才能做到零延迟，
因此刚打开视频的头几秒可能来不及处理。

**能认出「小爱同学」，认不出「小菜同学」**
这是识别方式决定的，不是故障。把变体添加进词表即可。

**添加了新词但没有生效**
添加后需要点「保存词表」，然后**刷新视频网页**。
如果确认都做了仍然无效，检查一下转换出的读音是否正确——多音字容易出错。

**引导页显示「未检测到引擎」**
下载的安装包里是自带引擎的，出现这个提示通常意味着解压不完整，
重新解压一次再加载即可。如果你是自己构建的，见
[CONTRIBUTING.md](CONTRIBUTING.md#构建与发布)。

**卸载后想重装 / 换个位置放**
在扩展列表里点「移除」，然后把文件夹放到新位置，重新走一遍第 3 步。
你的词表和设置保存在浏览器里，重装后仍在。

安装过程中的问题见[安装 → 遇到问题？](#遇到问题)。

## 它是怎么做到的

一般的做法是一边播放一边识别，但那样必然慢一拍——等认出唤醒词，
声音已经播出去了。

这个扩展换了个思路：**去读播放器已经下载好、但还没播的那段音频**。
你现在看到的画面，播放器往往在几十秒前就把后面的音频缓存好了。
扩展提前把这段音频解码、识别，记下唤醒词出现的时间点，
等播放真的到达那一刻时把音量降到零。

因此静音是精确的、没有延迟的，也不会造成音画不同步。

### 实测数据

| 指标 | 结果 | 测试素材 |
|---|---|---|
| 识别率 | 9 / 9 处 | 真实视频 |
| 识别率 | 94.9%（312 个片段） | 合成语料 |
| 误报 | 0 次 / 32 分钟 | 合成语料 ⚠️ |
| 识别速度 | 21 倍速（单核 CPU） | — |

> **误报那一行需要打个折扣。** 它是在合成语料上测得的，
> 而真实视频有背景音乐、多人同时说话、压缩失真，这些恰恰更容易引起误报。
> 真实素材上的误报率**目前还没有数据**，这是本项目当前最需要帮助的事情之一。

## 参与开发

最需要帮助的是**唤醒词表**：近音变体是长尾的、有地域性的、会随流行语变化的，
靠一个人维护并不现实。提交一个变体词的门槛最低，价值也最高。

架构说明、开发环境、测试方法、待办清单，以及若干技术细节，
