唤醒词防火墙

还差一步就能用。下面每一步能自动完成的都会自动完成。

1检测引擎

检查中…

唤醒词检测靠一个 WebAssembly 引擎。官方没有发布它的浏览器版—— k2-fsa 只为语音识别、语音合成、静音检测发布了 wasm，唯独没有关键词检测。 npm 上那份是 Node 专用构建（NODERAWFS），浏览器里加载会直接报错。

所以需要你本地编一次，约 20–40 分钟，一次搞定。编好后把文件拖进来即可， 不用重新打包扩展。

构建命令（点开看） 
git clone https://github.com/emscripten-core/emsdk.git
cd emsdk && ./emsdk install 4.0.23 && ./emsdk activate 4.0.23
source ./emsdk_env.sh && cd ..

git clone https://github.com/k2-fsa/sherpa-onnx.git
cd sherpa-onnx/wasm/kws/assets
P=sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01
curl -L -o m.tar.bz2 https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/$P.tar.bz2
tar xf m.tar.bz2 && rm m.tar.bz2
mv $P/encoder-epoch-12-avg-2-chunk-16-left-64.onnx ./
mv $P/decoder-epoch-12-avg-2-chunk-16-left-64.onnx ./
mv $P/joiner-epoch-12-avg-2-chunk-16-left-64.onnx ./
mv $P/tokens.txt ./ && rm -rf $P
cd ../../.. && ./build-wasm-simd-kws.sh

# 产物在 build-wasm-simd-kws/install/bin/wasm/
# 把 sherpa-onnx-wasm-kws-main.{js,wasm,data} 三个文件拖进引导页即可
把 sherpa-onnx-wasm-kws-main.js / .wasm / .data 拖到这里
也可以点击选择文件

2自检

用扩展内置的一段真实音频跑一遍完整检测链路，确认引擎真的能认出「小爱同学」。

3兼容性探测

有些播放器把 MediaSource 放在 Worker 里，那样扩展抓不到音频数据。 打开一个视频页（B 站 / YouTube 都行），回到这里点按钮，我来查。

4开始用

装好后打开任意视频页即可自动生效。点浏览器工具栏的图标可以调 静音时长和唤醒词表。

挡不住的情况已知有：DRM 内容（音频是密文）、杜比音轨（Chrome 无解码器）、 WebRTC 直播（无前瞻缓冲）。遇到时页面上会有提示，不会静默失效。
